▶ 공연 시작 (관람객 입장 전)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 위 주소로 제어 패널 접속
2. 상단 상태 표시줄이 "연결됨" 으로 바뀌는지 확인
3. [공연 제어] 섹션 → [▶ 시작] 버튼 클릭
   → 버튼이 초록색으로 빛나면 정상 시작
4. 자동 모드는 기본값 "빈도 반응형" 유지
   (관람객이 오면 자동 작동, 1분 부재 시 자동 정지)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⏹ 공연 종료 / 긴급 정지
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[공연 제어] → [⏹ 전체 스톱] 클릭
→ 모든 로봇 즉시 정지 + 사운드 정지

⚠ 제어 패널이 안 될 경우 전원 멀티탭에서 직접 OFF

🤖 로봇 상태 카드 읽는 법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GP (황금빛 꽃잎)  — R01 ~ R12  [초록 테두리]
IF (비결정적 유영) — R13 ~ R18  [보라 테두리]

카드 상태 표시:
  IDLE  = 대기 중 (정상)
  HEAT  = 가열 중 🔥
  SUST  = 온도 유지
  COOL  = 냉각 중 ❄
  ERR   = 오류 ⚠ → 아래 트러블슈팅 참고
  (흐릿한 카드) = 오프라인 (연결 끊김)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ 전원 제어 (스마트 플러그)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[전원 제어] 섹션에서 그룹별 ON / OFF / ↺(재시작)

  1 — 황금칩 꽃
  2 — 황금빛 꽃잎 1
  3 — 황금빛 꽃잎 2
  4 — 비결정적 유영
  5 — 아해들
  6 — 황금빛 꽃 조명

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🆘 트러블슈팅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
▸ 로봇 카드가 흐릿함 (오프라인)
  → [전원 제어] 해당 번호 [↺] 재시작 클릭
  → 30~60초 대기 후 카드 다시 밝아지는지 확인

▸ ERR 상태인 로봇
  → [전원 제어] 해당 번호 [↺] 재시작 클릭

▸ 전체 로봇 응답 없음
  → [⏹ 전체 스톱] 후 작가에게 연락

▸ 제어 패널 접속 불가
  → 휴대폰 Wi-Fi 또는 데이터 연결 확인
  → 현장 Wi-Fi 연결 후 내부 주소로 재시도:
     http://192.168.50.51:8181/sema_control.html

▸ MQTT 연결 오류 (상단에 빨간 표시)
  → 페이지 새로고침 (F5 또는 당겨서 새로고침)
  → 해결 안 되면 작가에게 연락
