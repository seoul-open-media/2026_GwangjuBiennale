GB16 2026 광주비엔날레 - 스텝 운영 매뉴얼

1. 접속 주소

  • 외부 제어: https://gb16.ngrok-free.dev/gb16_control.html
  • 외부 모니터: https://gb16.ngrok-free.dev/dashboard.html
  • 내부 제어: http://192.168.0.18:8182/gb16_control.html
  • 내부 모니터: http://192.168.0.18:8182/dashboard.html

외부 주소는 모바일 데이터 포함 어디서나 접속 가능, 내부 주소는 전시장 Wi-Fi 연결 시 사용.

2. 공연 시작 / 자동 실행

  1. 제어 패널 접속 후 상단 상태가 "MQTT 연결됨"인지 확인.
  2. 공연 제어에서 관객감지 ON 확인.
  3. 커스텀 타임라인 스텝이 비어있지 않은지 확인.
  4. 관객이 없음 -> 있음으로 바뀌는 순간 커스텀 타임라인 1회 자동 실행.
  5. 즉시 테스트는 커스텀 타임라인의 [실행] 버튼 사용.

3. 주요 제어 버튼

  • 공연 시작 (전체 ON)전원 그룹 1 -> 2 -> 3 순서로 전체 ON.
  • 전시 마감 (전체 OFF)확인 경고창에서 확인해야 전체 OFF 실행.
  • 전체 스톱커스텀 중단 + SOUND 정지 + RESET(all) 재전송.
  • HEAT_ON현재 파라미터 SET 후 가열 시작.
  • HEAT_OFF가열 중지.
  • RESET선택 대상 리셋.

4. 전원 제어 그룹

  • 그룹 1: IF + Bellshaker + Light1 (192.168.0.100)
  • 그룹 2: Domino (192.168.0.101)
  • 그룹 3: IF Ceiling + Light2 (192.168.0.102)

5. 트러블슈팅

  • 카드가 흐릿함(오프라인): 해당 그룹 전원 [↺] 재시작 후 30~60초 대기.
  • ERR 상태: 해당 그룹 전원 [↺] 재시작.
  • 관객 감지되는데 시작 안 됨: 관객감지 ON / 스텝 존재 / MQTT 연결 확인.
  • 전체 응답 없음: [전체 스톱] 후 작가 연락.
