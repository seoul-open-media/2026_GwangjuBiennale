GB16 수리 스텝 상세 매뉴얼 (버튼 기능 전체)

0. 수리 전 공통 체크

  1. 상단 상태가 "MQTT 연결됨"인지 확인.
  2. 수리 중 오동작 방지를 위해 필요 시 [전체 스톱] 먼저 실행.
  3. 대상 그룹(1/2/3)과 실제 장치 라벨 일치 확인.

1. 개별 전원 버튼 기능

  • 1 ON192.168.0.100 (IF + Bellshaker + Light1) 전원 켜기
  • 1 OFF192.168.0.100 전원 끄기
  • 1 ↺192.168.0.100 전원 재시작
  • 2 ON192.168.0.101 (Domino) 전원 켜기
  • 2 OFF192.168.0.101 전원 끄기
  • 2 ↺192.168.0.101 전원 재시작
  • 3 ON192.168.0.102 (IF Ceiling + Light2) 전원 켜기
  • 3 OFF192.168.0.102 전원 끄기
  • 3 ↺192.168.0.102 전원 재시작

2. 전시 전원 일괄 버튼

  • 전시 시작 (전체 ON)1 -> 2 -> 3 순서로 전체 ON 전송
  • 전시 마감 (전체 OFF)확인창에서 확인 시 1 -> 2 -> 3 순서로 전체 OFF 전송

전시 마감 확인창에서 취소하면 전원 상태는 변경되지 않습니다.

3. 공연/명령 버튼 기능

  • 시작커스텀 타임라인 즉시 실행
  • 전체 스톱커스텀 중단 + SOUND STOP + RESET(all) + RESET 재전송
  • HEAT_ONSET 후 가열 시작
  • HEAT_OFF가열 중지
  • RESET선택 대상 리셋
  • FAN_ON팬 단독 ON
  • FAN_OFF팬 OFF
  • SET 전송파라미터 반영만 수행
  • 스태거드 시작/중단분할 구동 시작/중단

4. 수리 표준 절차

  1. 증상 그룹 확인
  2. 해당 그룹 [↺] 1회 실행 후 30~60초 대기
  3. 복구 실패 시 [OFF] 5초 후 [ON]
  4. 복수 장애면 [전시 마감] -> 확인 -> [전시 시작]
  5. 여전히 실패하면 [전체 스톱] 후 작가 연락
